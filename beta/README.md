# Zorvian Beta Hub

`index.html` is the controlled entry point for external testers. `feedback.html` is a local scorecard and does not submit data to a server. `TESTER_BRIEF.md` defines the test protocol.

The hub intentionally does not contain API keys, production credentials, production customer data or unrestricted Core actions. Individual functional component demos should be attached only after their bounded demo endpoints and approval policies pass Gate 3 tests.
