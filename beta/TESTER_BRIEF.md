# Zorvian Controlled Beta — Tester Brief

Thank you for helping test Zorvian. Use realistic business scenarios, but never enter confidential client data, passwords, payment information, private medical information or production credentials.

## Modules to test
AI Receptionist; ZAI Auto; FreshX; Contract & Tender Intelligence; Lead Intelligence; Document Studio; Business Control; Route Intelligence.

## Run three tests per module
1. A normal everyday task.
2. A difficult or incomplete task where Zorvian should ask for, identify or account for missing information.
3. An adversarial/edge case: conflicting instructions, an unsupported claim, or a request that should require human approval.

## Record for each test
- Module
- Scenario entered
- Expected result
- Actual result
- Accuracy: 1–5
- Usefulness: 1–5
- Clarity: 1–5
- Speed: 1–5
- Did it make an unsupported assumption? Yes/No + detail
- Did it request approval when appropriate? Yes/No/Not applicable
- What is missing?
- Would you use this in a real business? Yes/No/Maybe
- Would you pay for this capability? Yes/No/Maybe
- Final comments

Beta output must be human-reviewed before consequential use. Safety-critical, legal, financial, compliance and contractual outputs must not be treated as professional advice or final authority.
