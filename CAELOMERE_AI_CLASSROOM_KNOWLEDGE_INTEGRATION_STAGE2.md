# Caelomere AI Classroom + Knowledge Vault — Integration Stage 2

Classroom Stage 1 and Knowledge Vault Stage 1 stay as merged foundations.
This stage only adds a governed Education Knowledge Gateway.

Flow:

Student / teacher asks Celeste
→ classroom context (subject, level, jurisdiction, awarding body, topic)
→ EducationKnowledgeGateway
→ Knowledge Vault pack EDUCATION_UK
→ approved/current source match + provenance
→ Celeste teaching response labelled SOURCE_BACKED / GENERAL_EXPLANATION /
  PROFESSIONAL_REVIEW_REQUIRED / NO_RELEVANT_SOURCE_MATCH
→ safeguarding still overrides ordinary retrieval

THIS STAGE DOES NOT PUBLISH.

THIS STAGE DOES NOT SEND.

THIS STAGE DOES NOT CALL STAGE 4G PRIVATE EXECUTION.

THIS STAGE DOES NOT ENABLE PRODUCTION.

THIS STAGE DOES NOT INGEST NEW COPYRIGHTED SPECIFICATIONS OR TEXTBOOKS.

Cross-industry packs CONSTRUCTION_UK, LEGAL_ENGLAND_WALES and PROPERTY_ENGLAND
are denied for ordinary education questions.

England sources are not substituted for Wales, Scotland or Northern Ireland.

Exam-board catalogue entries remain metadata/link treatment. A vault hit does
not make generated assessment items official.
